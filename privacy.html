개인정보처리방침

취향 진열장 · 시행일 2026년 10월 19일

짧게 말하면: 취향 진열장은 서버가 없어요. 올린 사진과 기록은 사용자 본인의 구글 드라이브에만 저장되고, 앱 만든 사람을 포함해 누구에게도 전송되지 않아요.

1. 어떤 앱인가요

취향 진열장(oceankitty9326.github.io/shelf)은 마음에 드는 물건 사진을 날짜별 선반에 올려 두는 웹 앱이에요. 모든 기능은 사용자의 브라우저 안에서만 동작해요.

2. 구글 계정으로 받는 권한

  • Google 드라이브 – 이 앱이 만든 파일만(drive.file): 드라이브에 '취향 진열장' 폴더를 만들고, 그 안에 사진과 설정 파일을 저장하고 읽어요. 이 앱이 만들지 않은 다른 드라이브 파일은 볼 수도 바꿀 수도 없어요.
  • 로그인한 계정의 이메일 주소는 다음 로그인 때 같은 계정을 바로 고를 수 있도록 사용자 기기 안에만 저장해요.

3. 저장되는 정보와 위치

  • 사용자의 구글 드라이브: 올린 사진(누끼 사진과 원본), 물건 이름·메모·날짜·선반 위치, 선반 배경과 칸 설정.
  • 사용자 기기(브라우저): 빠르게 보여주기 위한 사진 사본, 로그인 상태(약 1시간 유효), 화면 설정.
  • 앱 만든 사람은 별도의 서버나 데이터베이스를 운영하지 않으며, 위 정보를 수집·열람·보관하지 않아요.

4. 외부 서비스

  • Google: 로그인(Google Identity Services)과 드라이브 저장(Google Drive API). Google의 개인정보처리방침이 적용돼요.
  • 배경 지우기 AI: AI 모델 파일을 jsDelivr 등 공개 배포망에서 내려받아 기기 안에서 실행해요. 사진은 외부로 보내지 않아요.
  • GitHub Pages: 앱 화면 파일을 내려주는 곳이에요. 일반 웹사이트처럼 접속 기록이 GitHub에 남을 수 있어요.

광고, 분석 도구, 추적 쿠키는 쓰지 않아요. 정보를 판매하거나 제3자에게 제공하지 않아요.

5. 지우는 방법

  • 앱에서 물건을 빼면 다락방으로 가고, 30일 뒤 또는 '완전히 버리기'를 누르면 드라이브에서도 지워져요.
  • 전부 지우려면 구글 드라이브의 '취향 진열장' 폴더를 삭제하면 돼요.
  • 권한을 끊으려면 구글 계정 → 서드파티 앱 및 서비스에서 취향 진열장의 액세스를 삭제하세요. 기기 안의 사본은 앱 메뉴의 로그아웃이나 브라우저 사이트 데이터 삭제로 지워져요.
